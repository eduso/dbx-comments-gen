# Mapping de Insumos — Auditoría

Insumos **adicionales** que solo el proceso de auditoría carga, además de los que ya están en `mapping.md`. Útil para glosarios estrictos, políticas de naming, ejemplos de comentarios correctos/incorrectos, lineamientos editoriales, etc.

## Formato

Mismo que `mapping.md`:

- **Archivos:** `` `nombre_archivo.ext` ``: descripción de uso
- **Tablas:** `catalogo.esquema.tabla`: descripción de uso

Soporta los mismos hints opcionales (`[tabs: ...]`, `[columnas: ...]`).

Si este archivo no existe o está vacío, la auditoría usa únicamente los insumos de `mapping.md`.
